# Sound effects list (ElevenLabs prompts)

Sound effects only: no music, no voice. Built from the cues in `src/game/sfx.ts`, the `KernelEvent` list in `src/contracts/events.ts`, the enemy table in `src/game/bestiary.ts`, the laptop sounds (`src/laptop/runtime/sound.ts`) and the comix audio cues (`src/cinematic/audio.ts`).

## How to use

- Use the model **SFX v3** (`eleven_text_to_sound_v3`). It follows multi-part prompts ("first ..., then ..., finally ...") more closely than v2, which ElevenLabs has deprecated.
- Every prompt is standalone: paste it as is. Each prompt ends with its total length and is at most 450 characters, the API limit. Also set **Duration** by hand to the Length column (do not leave it on Auto) and set **Prompt influence** to High so the model stays literal.
- The API refuses a duration under 0.5 seconds. Cues listed shorter are generated at 0.5 seconds. The prompt still describes the shorter event, which ends in silence.
- Rows marked `loop`: generate them, then make the loop seamless with a short crossfade in an audio editor (or use ElevenLabs' Loop option).
- Generate 4 variations of every row and keep the best. For repeating sounds (keys, hops, hits, ticks) keep 3 or 4 variants and let the game pick one at random.
- Every prompt follows the same order: physical source and material, how it is made, a timeline (first, then, finally), pitch and tone, perspective, and how it ends. If a result is bad, edit the first sentence (the physical source) before anything else; do not add adjectives.
- Exact counts ("three beeps") are not always followed by the model. If a count matters, generate more variations and pick the one that has it.
- The "chiptune" rows name a waveform, a pitch and a note movement on purpose. The model follows notes and waveform names better than words like "retro" or "cute".
- Sounds that must not contain a voice (the emote rows) are described as sound design from air, strings or impacts. If a voice still appears, drop the word "sigh" or "shout" from the prompt and describe only the air or the impact.
- Every prompt ends on silence so files are easy to trim and loop in the engine.
- After export: trim the silence, normalise the peak to -3 dBFS, and export 44.1 kHz mono for UI and spot effects, stereo for ambience, thunder and boss sounds.
- The Name column is the short snake_case id; use it as the file name (for example `key_press.mp3`).
