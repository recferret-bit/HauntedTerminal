# Steamworks Registration, Coming Soon Store Page & Desktop Release Playbook

This playbook pairs with `.kiro/specs/steamworks-store-release/requirements.md` (`Status: draft`, holding the 10 founder decisions under `## Open questions`) and documents the exact external and in-repo steps to take **Out Of Credits** from its live browser demo + GitHub tagged desktop builds to a published Steam **Coming Soon** page, **Steam Next Fest** Demo, and **Full Steam Edition** launch.

---

## 1. Funnel Architecture (What Is Live Today)

1. **Top of Funnel — Instant Browser Demo (`/` -> `/play/chapter-01-kiroween`)**:
   - Visitors play all **11 zero-death-verified sectors** of Chapter 1 in their browser with zero install or signup friction.
   - Progress (`out-of-credits:progress:v1`), Silicon Scrap / `~/.bashrc` Rig Perks (`out-of-credits:metagame:v1`), and **15 local achievements** (`out-of-credits:achievements:v1`, keyed 1:1 with `ACH_*` Steamworks API names) persist locally.
2. **Mid Funnel — Dedicated Tagged Desktop Builds (`#desktop-builds` & GitHub Releases)**:
   - Pushing any `v*` git tag triggers `.github/workflows/desktop-release.yml`, running `npm run quality`, `generate-chapter.mjs --verify`, `npm run build`, `generate-tauri-steam.mjs`, and `verify-desktop-bundle.mjs`, then building native **macOS** (`.dmg`), **Windows** (`.msi` / `-setup.exe`), **Linux / Steam Deck** (`.AppImage` / `.deb`), and **Portable Offline Web** (`tar.gz`) artifacts with `SHA256SUMS.txt`.
   - Browser players click **Export Save & Trophies (.json)** on `/` and **Import Save Bundle (.json)** inside the desktop app to carry every sector clear, perk, and `ACH_*` trophy over immediately.
3. **Bottom of Funnel — Steam Coming Soon, Next Fest & Full Steam Edition**:
   - Visitors click **Wishlist on Steam (Coming Soon)** on `/` to save their Launch Pass (`out-of-credits:waitlist:v1`) and follow GitHub Releases; once your Steam App ID is live, setting `steamStoreUrl` in `src/chapters/steam-bridge.ts` switches every Wishlist CTA on `/` directly to `https://store.steampowered.com/app/<APP_ID>/`.

## 2. Step-by-Step Steamworks Partner Registration

1. **Create Your Steamworks Partner Account (`https://partner.steamgames.com`)**:
   - Sign in with a dedicated studio Steam account protected by Steam Guard Mobile Authenticator.
   - Choose legal entity structure (recorded in `.kiro/specs/steamworks-store-release/` Open Question #1):
     - *Sole Proprietor / Individual*: fastest 2–5 business day verification; legal name must match government ID, tax form, bank account, and `LICENSE` 1:1.
     - *Incorporated Studio (LLC / Corp)*: separates personal liability and displays studio legal name on the store page; requires incorporation certificate, EIN / tax ID, and company bank account in the exact entity name.
2. **Complete KYC, Tax & Banking Onboarding**:
   - Submit the Steam Distribution Agreement & NDA.
   - Complete the online tax interview (`W-9` for US entities/individuals; `W-8BEN` / `W-8BEN-E` for non-US developers to claim treaty withholding rates, typically 0%–10%).
   - Enter payout bank routing/IBAN/SWIFT details.
3. **Pay the $100 Steam Direct Fee**:
   - Generates your **Main App ID** (recoupable once the game passes $1,000 Adjusted Gross Revenue on Steam).
   - Inside App Admin, click **Create Associated Demo App** (free — no second $100 fee) to generate your **Demo App ID** for the free 11-level Chapter 1 Steam Demo.

## 3. Publishing the Steam "Coming Soon" Store Page

Valve reviews store presence separately from game builds, so you can publish your **Coming Soon** page and start collecting real wishlists weeks before uploading your final build:

- **Required Store Graphical Capsules** (no review scores, no fake award badges, no third-party logos):
  - Header Capsule: `920 x 430` PNG
  - Small Capsule: `462 x 174` PNG
  - Main Capsule: `1232 x 706` PNG
  - Vertical Capsule: `748 x 896` PNG
  - Library Capsule: `600 x 900` PNG, Library Header: `920 x 430` PNG, Library Hero: `3840 x 1240` PNG, Library Logo: `1280 x 720` transparent PNG
- **Screenshots & Trailer**:
  - Minimum **5 actual `1920 x 1080` gameplay screenshots** (capture directly from `/play`, `/comic.html`, and `/storybook.html` — e.g., Level 1 Kiro Ghost tutorial, `chmod -x` petrifying a trojan, Split Code Editor fixing `cart.js`, Matrix Greybeard hub rebooting `qwen`, and Clod + Kernel Boss).
  - **45–60s Gameplay Trailer**: open in the first 3 seconds with real terminal input triggering 3D comic action (`ls -la` -> `.spycam` revealed -> `kill -9` lightning strike). Use only original/procedural audio.
- **Content Survey & Disclosure**:
  - Complete the Steam Content Survey (ratings) and confirm that all assets in Out Of Credits are deterministically generated by code (`src/procgen`), not runtime generative AI APIs.
- **Minimum 14-Day Coming Soon Window**:
  - A Steam store page must remain publicly visible as "Coming Soon" for at least **14 days** before paid launch.

## 5. Building Tauri + Steamworks & Pushing Tagged Releases

### Local Commands

```bash
# 1. Run unit tests for icon generation, offline bundle checks & ACH_* Rust sync
npm run desktop:test

# 2. Generate src-tauri/ (standalone by default; add --steam-dev for Spacewar App ID 480)
npm run desktop:generate
node scripts/desktop/generate-tauri-steam.mjs --steam-dev

# 3. Verify dist/ has zero external CDNs, bundled .woff2 fonts & synced ACH_* manifest
npm run build && npm run desktop:verify

# 4. Dry-run or build native installers (requires Rust / Cargo)
node scripts/desktop/build-tauri-steam.mjs --dry-run
npm run desktop:build

# 5. Build with live Steamworks SDK feature (stages `libsteam_api.dylib` / `steam_api64.dll` / `libsteam_api.so` directly into `.app`/`.dmg`, `.msi`/`-setup.exe`, and `.deb`/`.AppImage` bundles before signing)
node scripts/desktop/build-tauri-steam.mjs --steam --app-id <YOUR_STEAM_APP_ID>
```

### Publishing a Downloadable Build on GitHub Tags

```bash
git tag v0.1.0
git push origin v0.1.0
```

`.github/workflows/desktop-release.yml` automatically runs `npm run quality`, `generate-chapter.mjs --verify`, `desktop-unit.mjs`, builds macOS `.dmg`, Windows `.msi`/`.exe`, Linux `.AppImage`/`.deb`, and portable offline `.tar.gz` bundles, generates `SHA256SUMS.txt`, and publishes them to the `v0.1.0` GitHub Release.
