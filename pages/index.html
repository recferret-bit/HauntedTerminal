Will my browser demo saves and 12 ACH_* achievements transfer to Steam?

Yes. Every sector rank, Silicon Scrap perk, and local trophy uses its exact 1:1 Steamworks API key (ACH_FIRST_BOOT through ACH_ZERO_PANIC_RUN). Export haunted-terminal-save.json here (or on the Chapter 1 Victory Screen) and import it in the desktop/Steam build to sync automatically to SteamUserStats and Steam Auto-Cloud.

Are the Unix, JavaScript, and Docker commands real or scripted QTEs?

Real syntax and real execution. You navigate a live virtual filesystem with pipes, globs, redirects, octals (chmod 755 / chmod -x), and signals (kill -9), repair live HTML/CSS and JavaScript inside a sandboxed split editor, and author valid Dockerfile and docker-compose.yml specs verified by deterministic gates.

Does the desktop game run 100% offline and on Linux / Steam Deck?

Yes. All runtime fonts (Chakra Petch & IBM Plex Mono SIL OFL .woff2), procedural 3D assets, and WebAudio effects are bundled locally with zero CDN calls, verified on every build by npm run desktop:verify. Linux .AppImage / .deb builds run natively on SteamOS with physical or Steam Virtual Keyboard input.
