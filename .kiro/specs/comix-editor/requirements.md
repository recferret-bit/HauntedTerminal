# Comix editor studio: requirements

The Comix Editor (`/comix-editor`) is a workstation studio in `src/comix-editor/` built on `src/editor-core/` and `src/styles/editor-workstation.css` for reviewing, scrubbing, framing, and tuning connected `comix/<slug>/` sequences on desktop and headless Chrome, without owning separate game or comix logic.

## Requirements

1. **Connected multi-file model & conflict-safe saving.** WHEN loading or saving a sequence, THE EDITOR SHALL track per-file baselines (`comix.manifest.json` and each `page.spec.json`), highlight dirty pages, sync manifest page summaries (`syncSummaries()`), write canonical JSON via `stringifyComixJson`, enforce local/same-origin `application/json` requests in `/api/comix`, reject stale writes with `409`, and detect external disk changes including page additions/deletions.
2. **Schema-driven Inspector forms & 2D Page Mini-Map.** WHEN editing Manifest, Stage & Set, Cast, Page Overview, Panels & Camera, Letters, or Beats & Tracks, THE INSPECTOR SHALL render fields exhaustively from `schema*.ts`, provide an interactive drag/resize 2D Landscape/Portrait sheet mini-map (`sheet-drag.ts`), offer `ModelCatalog` / `FxCatalog` / cue / landmark datalists (`suggest.ts`), and run static + 60fps `simulateComixPack` diagnostics (`check.ts`).
3. **Game-engine workspace with hidable, draggable, resizable docks.** WHEN arranging the workstation, THE WORKSPACE SHALL center the Comix Viewport (`stageEl`), allow every dock (`top`, `left`, `right`, `timeline`, `jumps`, `stagebar`) plus Focus/Zen mode (`zen`) to toggle and persist in `localStorage`, support splitter resizing, drag-to-float windows, left/right dock swapping, `↺ Layout` reset, and direct edge/corner viewport resizing (`view-resizer.ts`).
4. **Live draft viewport, zoom, pan & Apply Shot.** WHEN scrubbing or playing the preview, THE PREVIEW SHALL push unsaved drafts to `/cinematic.html?draft=1&editor=1` (`localStorage`), sync playhead/active-panel highlights at runtime, support page zoom (`Fit` / `40%–250%`), orthographic 3D camera zoom (`0.25×–6.0×`) and pan, and write the framed shot back to `camera.from`, `camera.to`, or `camera.portrait` (`Apply Shot`).
5. **Bidirectional viewport <-> Inspector selection.** WHEN clicking a 2D letter, 2D title overlay, panel background, 3D cast actor, 3D prop, or 3D fixture in the Comix Viewport — or selecting/focusing an element row, panel section, or mini-map box in the Inspector — THE EDITOR SHALL highlight the element in the Viewport (`EditorSelectionOverlay` marquee + `.cx-sel-pill`), reveal & expand the corresponding `<details class="item is-selected">` / `.panel-sec.is-selected` / `.layout-box.is-selected` row in the Inspector, seek the preview if an Inspector-picked item is currently hidden, and preserve focused `<input>`/`<select>`/`<textarea>` elements during in-pane selection.
6. **Accessibility & verification gates.** THE EDITOR SHALL build DOM strictly with `h()`, label multi-control fields via `role="group"`, support keyboard controls across splitters/tabs/resizers/mini-map/issue jumps (`Ctrl/Cmd+S`, `Ctrl/Cmd+Shift+S`), stay within file/function size & duplicate limits (`npm run quality`), and pass `scripts/harness/editor-unit-test.mjs` and headless Chrome checks in `scripts/harness/comix-editor-smoke.mjs`.
