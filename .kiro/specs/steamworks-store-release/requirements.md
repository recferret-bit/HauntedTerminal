# Steamworks Partner registration, Coming Soon store page & live SDK cutover: requirements

Status: draft

Capability: External Steamworks Partner onboarding, Steam "Coming Soon" store page publication, Chapter 1 Steam Demo & Steam Next Fest entry, OS code-signing/notarization, and cutting Haunted Terminal's local `ACH_*` achievements and JSON saves over to live Steamworks (`STEAM_APP_ID`, Steam Achievements, and Steam Cloud) once Valve issues App IDs. All engineering scaffolding (landing funnel, local `ACH_*` achievements, offline fonts, Tauri v2 + `steamworks` generator, and GitHub tagged desktop builds) is implemented in `.kiro/specs/steam-launch-funnel/`; the unresolved partner, legal, store-asset, and live-cutover decisions below are saved here as open questions for the founder. Companion checklist: `docs/STEAM_RELEASE_PLAYBOOK.md`.

## Requirements

1. WHEN a real Steam App ID is issued by Valve, THE SYSTEM SHALL set `steamAppId` and `steamStoreUrl` in `src/chapters/steam-bridge.ts` / `scripts/desktop/desktop-config.mjs` so the `/` "Wishlist on Steam" CTA links directly to `https://store.steampowered.com/app/<APP_ID>/` with UTM funnel attribution.
2. WHEN building the Steam depot binary (`node scripts/desktop/build-tauri-steam.mjs --steam --app-id <APP_ID>`), THE SYSTEM SHALL enable the `steam` Cargo feature in `src-tauri/Cargo.toml`, automatically stage the platform `steam_api` redistributable library (`libsteam_api.dylib`, `steam_api64.dll`, `libsteam_api.so`) next to the executable (with `-Wl,-rpath,$ORIGIN` on Linux), and omit `steam_appid.txt` from release depot uploads.
3. WHEN the desktop game boots under the Steam client with `steam` enabled, THE SYSTEM SHALL initialize `steamworks::Client::init_app(<APP_ID>)`, call `ISteamUserStats::RequestCurrentStats()`, register `UserStatsReceived` to replay local `ACH_*` unlocks idempotently via `store_stats()`, route Steam Store links into the native Steam Game Overlay (`ActivateGameOverlayToWebPage`), and invoke `ShowFloatingGamepadTextInput` on Steam Deck terminal focus.
4. IF the player launches the Steam build while offline or without the Steam client running, THEN THE SYSTEM SHALL fall back cleanly to local achievement/progress persistence without crashing or blocking gameplay.
5. WHEN publishing the free Chapter 1 Steam Demo alongside the Full Steam Edition Coming Soon page, THE SYSTEM SHALL package the 11-level Kiroween campaign under the dedicated Steam Demo App ID (`STEAM_DEMO_APP_ID`) and share save/achievement files via Steam Cloud Auto-Cloud paths so Demo progress carries into the Full Edition.
