## The agent (table entry)

| Field | Value |
|---|---|
| description | Owns the game's sound: SFX, music beds and voice lines in `public/sfx` and `public/music`, their prompt lists and manifests, and the event-to-cue mapping in `src/audio`. Generates with ElevenLabs only through `audio-gen.mjs`, under a credit cap. |
| writes | `public/sfx/**`, `public/music/**`, `docs/audio/*.md`, `src/audio/**`, `scripts/harness/audio-unit.mjs`, `scripts/harness/audio-smoke.mjs` |
| resources | `steer('skills-map')`, `app-events-audio/{requirements,design}.md`, `audio-agent/requirements.md` |
| skills | `sfx-and-music-pipeline`, `elevenlabs-{shared,text-to-sound-effects,music,text-to-speech,voices,audio-effects,usage,models}` |
| mcp | none |
| welcome | `sound-designer: which sound, music bed or voice line should I write, generate or map?` |

The shell is the shared allow-list. Nothing is added: `node scripts/harness/audio-gen.mjs ...` is covered by `node scripts/*`. The raw `elevenlabs` binary stays refused by the catch-all deny, `--output` by `DENY_WORDS`.

`lead-dev` gains `subagent/sound-designer`; the sub-agent's writes join the lead's session fence, as for every sub-agent. The lead's own writes gain `scripts/harness/audio-gen.mjs`, `scripts/harness/lib/audio-gen-*.mjs` and `scripts/harness/audio-gen-unit.mjs`, and lose `src/audio/**`.

Resource budget: 8 base `file://` files + 4 = 12 of 32; `skill://` entries do not count against the file limit.

## The wrapper `audio-gen.mjs`

```
node scripts/harness/audio-gen.mjs plan <cue>... [--variants N] [--text "<line>"]   request(s) + estimated cost (dry run)
node scripts/harness/audio-gen.mjs plan <cue>... --generate                        generate, post-process, patch manifest
node scripts/harness/audio-gen.mjs credits                                          used, limit, remaining, cap, reserve
node scripts/harness/audio-gen.mjs schema <resource> [<method>]                     the CLI's --schema output
node scripts/harness/audio-gen.mjs --check                                          offline consistency check (Req 11)
```

- **Rows.** A cue is a Name of a table row in `docs/audio/SFX_LIST.md` or `MUSIC_LIST.md` (`` `key_press` `` or a range `` `taunt_clod_1` .. `_10` ``). SFX rows give prompt and length. Music rows give prompt, length and `loop`; a plan in `public/music/plans/<name>.json` wins over the prompt (never both). Voice rows (`taunt_*`, `kiro_advice*`) give the voice, `eleven_v4` and the `robot` filter; the line comes from `--text` and is stored in the manifest entry (`text`, `voice`), because the lists hold only examples.
- **Request.** An argv array run with `execFileSync('elevenlabs', argv)`, no shell, so prompts need no escaping. SFX: `eleven_text_to_sound_v3`, prompt influence 0.8, `--duration-seconds max(0.5, listed)`, `--loop` on loop rows. Music: `music_v2_5`, `--music-length-ms`, `--force-instrumental true`. Speech: `text-to-speech convert --voice-id --model-id eleven_v4 --audio-effects.filter-preset-id <robot>`; voice and preset ids are looked up once (`voices search`, `audio-effects get_catalog`) and cached in git-ignored `scripts/harness/out/audio-gen/ids.json`. All: `mp3_44100_192` and an `--intent` naming the cue. The output path is computed from the cue name (`/^[a-z0-9_]+$/`) as `public/<sfx|music>/<name>[_<n>].mp3`; a caller cannot pass a path.
- **Credits (Req 7).** Before `--generate`: `user subscription get` gives `remaining = character_limit - character_count`. The estimate comes from a table in the wrapper (SFX per second, music per millisecond, speech per character), times variants. Refuse when `estimate > 15000` or `remaining - estimate < 30000`. After each request the subscription is read again; the run stops if the measured spend passes the cap, and prints estimated and measured spend. Cap and reserve are constants in the wrapper, which `lead-dev` owns (Q11).
- **Auth (Req 8).** If `elevenlabs auth status --format json` shows no active source: exit 1, "not logged in: run `elevenlabs auth login`". The wrapper never reads `.env`, never passes `--xi-api-key`, and prints only counts and tier from the subscription.
- **Post (Req 9).** With `ffmpeg`: `silenceremove` at both ends (one-shots only), a gain to a -3 dBFS peak measured with `volumedetect`, and on loop rows a one-bar `acrossfade` of tail into head; written to a temp file, then renamed over the raw file. Without it: the raw file stays, exit 3, "post skipped: brew install ffmpeg", and the entry gets `"post": false`.
- **Manifest.** Patched, never rewritten: read from disk right before the write, only the cue's entry changes (`files`, `bytes`, `duration_seconds`, `text`/`voice`, `post`), key order and 2-space format kept, written atomically (temp + rename).
- **Check (Req 11).** No network. Exit 1 on a manifest file entry without its mp3, an mp3 without an entry, an entry name in no list row (ranges expanded), or a name no app event or scene maps to. The mapping is read through the same code `audio-unit.mjs` uses for "every cue is mapped" (`src/audio/catalog.ts`), so the two agree.

## Guard hook

`violation()` gains one rule: a sub-command that runs a path ending in `audio-gen.mjs` with the word `--generate` is refused unless the agent is `sound-designer` ("generation spends ElevenLabs credits: only sound-designer runs --generate"). The hook already gets the agent name as its argument. To probe in task 2: whether Kiro also runs the parent's (`lead-dev`) PreToolUse hook on a sub-agent's command. If it does, the result goes to the user before anything is loosened.

## Skills

- `mv skills/elevenlabs-* .kiro/skills/`, then `rmdir skills`. The folder is untracked, so no git history moves.
- In each moved `SKILL.md`, only the `description:` value changes, to `"[AUDIO] ..."`. The bodies stay as the CLI generated them, so a later `elevenlabs generate-skills` can be diffed; the relative `../elevenlabs-shared/SKILL.md` links still resolve.
- `sfx-and-music-pipeline/SKILL.md` (`[AUDIO]`): when to use it; folders, lists and manifests; models and settings; variants and naming (`name.mp3`, `name_2.mp3`, ...); the wrapper (dry run first, `--generate` only when the brief says generate, the cap and the reserve); post-processing and `ffmpeg`; how to map a new cue in `src/audio/` (`sfx-*.ts`, `music-for.ts`) and prove it with `audio-unit.mjs`; what never goes into a prompt (commercial games, composers, voices of real people, personal data in `--intent`). The prompt-writing rules stay in the two lists; the skill points to them.
- `check-agents.mjs` gains a skill check: every `.kiro/skills/*/SKILL.md` has `name` and `description`, and the description starts with `[WORKFLOW]`, `[ASSET PCG]`, `[LEVEL GEN]` or `[AUDIO]`.

## Gates and qa

- `sound-designer` prompt gates: `npm run quality`, `node scripts/harness/audio-unit.mjs`, `node scripts/harness/audio-smoke.mjs`, `node scripts/harness/audio-gen.mjs --check`.
- `qa` prompt: when audio is in scope, run `audio-unit.mjs` and `audio-smoke.mjs` and `audio-gen.mjs --check`; never judge sound by ear (say "not judged: needs a person listening").
- `lead-dev` prompt: one delegation row ("a sound effect, music bed, voice line, or which event plays which cue: `sound-designer`"); a request that needs new assets runs `sound-designer` before the mapping is checked by `qa`; never pass `--generate` in a brief unless the user asked for generation in words.

## Decisions

- **The lists move to `docs/audio/`.** `lead-dev` owns `docs/*.md` and `check-agents.mjs` requires exactly one owner per file. `docs/audio/*.md` is outside that single-star glob, so the two lists get one owner without special cases in the gate. Rejected: a "most specific glob wins" rule in the gate (changes how every other path is judged). Follows Q2; the only reference to fix is a link inside `MUSIC_LIST.md`.
- **No raw `elevenlabs` in any shell.** Even read-only `--schema` goes through `audio-gen.mjs schema`, so the allow-list stays unchanged and the only path to the API is the capped wrapper. Follows Q3.
- **`--generate` is a guard-hook rule, not a shell rule.** Shell rules see command words with globs, and `node scripts/*` must stay allowed for every agent; the hook already parses sub-commands and knows the agent. Follows Q3, Q4.
- **The estimate table is conservative and checked after each request.** ElevenLabs prices change; measured spend after each request catches a wrong estimate before a second request runs. Follows Q6.
- **Voice line text lives in the manifest entry.** The lists name voices and give examples, not the 50 lines; the manifest already holds one entry per file. Follows Q7.
- **`ffmpeg` stays optional for gates.** CI and other machines may not have it; only the post step needs it. Follows Q8.
- **The fake CLI in the unit suite.** `audio-gen-unit.mjs` puts a Node script named `elevenlabs` (and `ffmpeg`) first on a temp `PATH`, which logs its argv and writes a small mp3 stub, against a temporary copy of the lists and manifests. No test spends credits or needs a network.

## Layers and gates

- No `src/` layer change: `src/audio/` only changes owner. No new page, route, model category or fingerprint impact.
- Vocabulary: a new skill category tag `[AUDIO]` (`skills-map.md`, `glossary.md` "Categories").
- `npm run quality:agents` covers the table, fence, ownership, rule self-tests, skill tags and `agents-unit.mjs`; `audio-gen-unit.mjs` runs inside `quality:agents` (it guards the cap). `npm run quality:root` proves `skills/` is gone.
