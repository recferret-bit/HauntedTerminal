# Terminal Lab rules

Facts for code under `src/terminal-lab/` (built on `src/editor-core/`), shared lab helpers in `src/game/lab-*.ts`, the chapter lab session in `src/chapters/session-lab*.ts`, and the Node side in `scripts/harness/lib/{terminal-lab-api,lab-run,lab-json}.mjs`. Spec: `.kiro/specs/inventory/items/terminal/`. The lab is a test bench: it is not declarative chapter data and it adds no chapter or comix vocabulary.

- **Reuse the game, never copy it.** A lab script compiles (`lab-pack.ts`) into a one-level `ChapterPack` plus a `LabConfig` (driver, clock, props, riddles, checks, task ids, classic setup). The game plays it through `?draft=1&lab=1` and swaps sessions in-page on edits via `window.__lab.swap(packId, levelId)` (`src/play/lab.ts`); the config travels next to the draft (`src/chapters/lab-config.ts`) and is normalised on read, since storage is untrusted. Both `driver: 'chapter'` (`ChapterSession`) and `driver: 'classic'` (`createSession({ lab })` in `src/game/session.ts`) run on the real shell, enemies, validators, Kiro and stage, sharing `src/game/lab-*.ts`. `level-import.ts` converts any chapter level into a standalone lab (`?from=<chapter>/<level>`, read-only toward `chapters/`). If the lab needs something from the game, extend the generic `lab` option or a read-only method (`inspect`, `labTick`, `inject`), never a branch that knows a lab.
- **Nobody is hurt.** A lab session counts damage per source in `rt.lab.absorbed` and applies none. Enemies still attack and animate; the end-of-level truce is off. `enemyFire: hold` is the separate switch that stops attacks. `terminal-lab.mjs` runs every committed lab plus a 30-tick soak and fails on any `PLAYER_DAMAGED` or `PLAYER_RESPAWNED`.
- **Turn-based clock** (`.kiro/specs/turn-based-battles/`). Combat is turn based in the lab too: every command is followed by one world step (an enemy turn in a battle). The manual clock stops `tick()`; `labTick()` (the Tick button, a `tick` step) is one second of the level clock, then the enemy turn of a running battle (forced, as a turn timer runout would be) or one free world step outside one. The live clock runs the battle intro and the 30-second turn timer; nothing hurts in real time.
- **The lab script is the single source of truth.** Every UI action edits it through `LabModel` (`lab-model.ts`); the selection is an item path (`setup[i]`, `steps[i]`, or null for the settings), as in the editors. Forms come from `schema.ts`; files, enemies, pickups, patches and win rules reuse the chapter editor's field tables and `makeSuggest`. A new setup or step op is: the type (`lab-types.ts`), `lab-pack.ts` or `runner.ts`, `schema.ts`, `lab-check.ts` / `store.ts`, `catalog.ts` if it is placeable, and a fixture. Typed `Record<Kind, ...>` tables make `tsc` fail until each is done; the PreToolUse guard asks before these files change.
- **Patterns are explicit.** Plain text is a substring (a riddle answer: the exact text); `re:<regex>` or `re:/<regex>/<flags>` is a regular expression (`isRegexPattern`, `matchesPattern` in `session-lab-checks.ts`). `checkLab` reports a pattern that does not compile.
- **Goals.** `inspect().goals` lists tasks (win rules), then checks, then riddles, each with `done`. `ran`, `output`, `code` and `event` checks latch, and are observed on every command, tick and inject. Riddles match their socket by absolute path.
- **One runner, two drivers.** `runner.ts` has no DOM and no game rules; `frame-driver.ts` (browser) and `node-driver.ts` (headless) must give byte-identical transcripts for the same lab (`transcriptOf`, no wall-clock). `terminal-lab-smoke.mjs` compares them for every committed lab.
- **Palette from the catalogs.** Objects come from `BESTIARY`, `PICKUP_INFO`, `ModelCatalog`, `RULE_VARIANTS` and the agents list, placed by click or HTML5 drag-and-drop (`palette-drag.ts`, onto the viewport stage for horizontal prop `x` or the Scene list for insertion index). `expectedPaletteIds()` and the unit test fail when a game id is missing. Every palette entry placed alone must give a lab with no errors that boots (e.g., `crack` pairs with a `worm` + sealed port when none exists).
- **Commands are read from the session.** `probeCommands()` takes the list from Tab completion and finds the ones the shell does not implement. A command the game adds must be grouped in `commands.ts` (`ungrouped()` fails the unit test).
- **Shared workstation pieces.** The game preview is `GamePreviewShell` + `PlayFrame` from `editor-core/` (shared with the chapter editor), disk polling is `pollDisk`, the top bar is `workstationChrome.topBar`, the Checks list is `renderIssueList`, the JSON tab is `renderJsonFilePane`, the repo baseline is the model's etag. Do not add lab-only copies of these.
- **Dev-only API.** `terminal-lab-api.mjs` (`devApiPlugin`, `editor-api-common.mjs`) keeps: local Host and same Origin only, `Content-Type: application/json`, JSON object bodies, only lowercase `<id>.lab.json` files directly in the labs folder with the id equal to the name, atomic writes through `lab-json.mjs`, a 409 on a stale or missing `baseEtag` (and when creating over an existing file), no delete, at most 200 files. `TERMINAL_LAB_DIR` moves the folder (the smoke test uses a temporary copy). Weakening any of these needs a reason in the change. `terminal-lab-api-test.mjs` covers each.
- **Workstation UX and accessibility.** Build DOM with `h()` (no `innerHTML`); redraw with `redrawKeepingFocus`, so a live refresh never takes a field away from someone typing; roving `[role="tablist"]` for the Inspector; real buttons for every action; `role="log"` and `role="status"` for the event log and the status line; one top-bar row at 1600 and 1280 px. Keep files under 600 lines, functions under 130, 0 duplicate blocks (`npm run quality`).
- **Layers.** `terminal-lab/` may import `contracts/`, `editor-core/`, `chapter-editor/` (field tables and suggest only), `game/`, `chapters/`, `procgen/` (`scripts/quality/check-layers.mjs`). `editor-core/` imports `contracts/` only.
- **Verification.** `terminal-lab-unit.mjs`, `terminal-lab-api-test.mjs`, `terminal-lab.mjs --all`, `terminal-lab-smoke.mjs` (also with `--width 1280 --height 820`), then `npm run quality`. Add `editor-unit-test.mjs`, `editor-smoke.mjs`, `comix-editor-smoke.mjs` and `generate-chapter.mjs --verify` when `editor-core/`, `chapter-editor/` or the chapter session changed. `verify-chapter.mjs` runs the first three.
