# Glossary

Use these words exactly; do not invent synonyms.

- **Chapter**: one folder `chapters/<slug>/`: manifest, levels, story. Kiroween ships one.
- **Comix**: one connected folder `comix/<slug>/` (`comix.manifest.json` + `pages/page-XX-<slug>/page.spec.json`), compiled to `src/cinematic/generated/` and played by `src/cinematic/`. Intro and outro are comixes, and any additional 3D comic sequence uses the same structure.
- **Level**: one `level.spec.json`: files, enemies, pickups, patches, win rules, solution, `script`.
- **Spec**: any of the chapter JSON files. Specs are the single source of truth; `src/chapters/generated/` is compiled output.
- **Pack** (`ChapterPack`): manifest + levels + dialogs + comic, as the game consumes them. The compiled pack is `getChapterPack`; a **draft** is an unsaved pack from the editor.
- **Script** (`level.spec.json -> script`): the declarative behaviour of a level. Made of **steps** (`print`, `say`, `dialogue`, `dialog_box`, `taunt`, `emote`, `spawn`, `kiro_action`, `tutorial_step`), **triggers** (`when`, `steps`), and **conditions** (`ran_command`, `file_absent`, `file_read`, `enemy_dead`, `has_item`, `room_swept`, `any`, `all`, ...).
- **Vocabulary**: the set of step, condition and field kinds the engine understands (`script-types.ts`, `types.ts`).
- **Dialog box**: the single unified comic box on the play screen (`src/ui/dialog-box.ts`, coordinated by `DialogOrchestrator` in `src/ui/dialog-orchestrator.ts`) with pixel-art filtered, calm idle-animated 3D-head portraits (`drawPortrait` in `src/renderer/portrait.ts`, 4 stepped idle head poses, zero CSS transforms or vertical bounce), speaker name, and one line, animating in on appear and out on disappear. Both `DIALOG_BOX` and `AGENT_TAUNT` share one ordered queue (`maxConcurrent <= 1`): `vibecoder` lines extend the permanent top-left `#hero-hud` card (`src/ui/hud.ts`, avatar with 5 Doom/Quake HP face tiers + `'ouch'` state over `#hud-hp-cell`, out-of-flow horizontal `#hero-dialog-drawer`), while NPC and AI-agent lines dock in `.dialog-box.side-right` on the right, coordinating with `.hint-note`, `#tutorial-card` (left-side KIRO.D prompt card below the items strip), and 3D in-room `dialogue` socket speech balloons (`.st-balloon`). It is not the `<dialog>` of the Steam waitlist.
- **Timed entry** (`script.timed`): `{ afterSec, steps }`, run when the level's tick counter reaches `afterSec` (real seconds, one `tick()` a second, paused with the game). It is the only real-time clock besides the battle clock, and it never makes an enemy act. Headless solves tick the same way.
- **App bus**: the in-process pub/sub in `src/contracts/app-bus.ts`. Kernel events, clicks, keys, commands and scene changes are **app events**. The SFX orchestrator, the music orchestrator, and later analytics subscribe. They do not call each other. Spec: `.kiro/specs/app-events-audio/`.
- **SFX orchestrator**: plays `public/sfx` when an app event maps to a sample (`src/audio/`).
- **Music orchestrator**: plays one `public/music` bed for the current scene. The Esc menu bed does not pause the clock or the turn timer.
- **Sound source**: one simultaneous one-shot voice. The pool size is configurable and starts at 10 (`SOUND_SOURCES`).
- **Battle**: turn-based combat, the only combat mode (no Tactical Mode, no real-time damage). It begins when the hero is in a room with a live enemy that can hurt him and ends when none is left there (`cleared`), he walks out (`left`), a backup restores him (`respawn`) or the level changes (`level`). One **battle orchestrator** (`src/game/battle.ts`, a pure state machine) says who acts now: `idle`, `intro`, `player`, `enemy`. Spec: `.kiro/specs/turn-based-battles/`.
- **Battle intro**: about 10 seconds (`INTRO_SEC`) before every battle: an agent of the big four taunts the vibecoder, Kiro.d gives one advice line, then FIGHT! (`fx.fight`). Enter skips it; the typed line stays on the prompt.
- **Turn**: the player always acts first. Every non-empty line sent with Enter is one player **action**, correct or not, answered by one **enemy turn** (one world step: each enemy tells or strikes on its cadence). An empty line is no action.
- **Turn timer**: 30 seconds per player turn; when it runs out the enemy turn runs anyway. It pauses with the game, during the intro, and while the `edit` mini-editor is open (`holdTurnTimer`); it runs while a dialog box or the in-game laptop overlay shows.
- **Lock** (`script.locks`): `{ command, until, message }`; the command is refused with `message` until the condition `until` holds. Level 6 locks `edit` and `sed` until `has_item laptop`. Separately, `ls` option flags (`-a`, `-A`, `-l`, `-la`, etc.) are gated in both shells (`hasLsFlags`, bypassed in Terminal Lab) until `has_item tube_transistor`, while basic `ls [path]` always lists visible entries.
- **Terminal skin**: the window chrome around the play page's terminal, one of six (`src/contracts/terminal-skins.ts`): iTerm2, macOS Terminal, PuTTY, Windows Terminal, GNOME Terminal, VT100. Changed with `skin <id>` or the Esc menu; the terminal's text, colours and font are the same in every skin. Not a theme of the game.
- **Items strip**: the HUD row with one slot per inventory item (`src/ui/items-strip.ts`): dim = not carried, highlighted = held (`manual` and `map` slots open their dialogs on click). `GameSnapshot.inventory` feeds it.
- **Dark** (`RoomView.dark`): true while the developer does not carry the Tube Transistor; the stage then lights him only with his terminal's glow.
- **Esc menu**: the modal menu Esc opens during play (`src/ui/esc-menu.ts`, wired in `src/play/menu.ts`): level details, sound (mute and volume, saved under `SOUND_PREF_KEY`), Restart level (two steps) and Back to main menu (one confirm line). It is not a pause: it adds no pause reason, never holds the turn timer, and a battle turn timer keeps running under it. Spec: `.kiro/specs/esc-menu-hud-rework/`.
- **`restart-level`** (alias `retry`): reloads the current level. A bare run arms a confirm; the next line being `restart-level` again, or `--yes` at once, restarts; any other line, a level change or more than 20 ticks expires it. Not `restart` (Play Again after the chapter ends). Rule in `src/game/commands-proc.ts`, used by both shells.
- **Random PID** (`src/chapters/pids.ts`): every enemy with a `pid` in its level spec (except PID 1, the boss) gets a new PID in 1100-8899 on every level load; the spec number is only a marker. Text and `solutionCommands` name it `{pid:<enemy id>}`, filled when the level loads (text) or the line is typed (`exec`). Labs keep the author's PIDs. `pidSeed` (a session option) makes a roll repeatable for tests. Spec: `.kiro/specs/random-pids/`.
- **Interpreter**: `src/chapters/script.ts`, the only code that acts on a script.
- **Win rule**: a condition on the world that must hold for the exit gate to open. Not a script condition.
- **Grant**: hardware or a Kiro core a player already owns when entering a late level directly (`manifest.grants`).
- **Dossier**: codex cards a chapter adds (`manifest.dossier`).
- **Preview**: the real game in an iframe on a draft (`?draft=1`); it records nothing.
- **Field table**: an entry in `src/chapter-editor/schema.ts`; it drives the form and the schema check.
- **Gate**: a script that fails the build (`npm run quality`, `--verify`, `editor-smoke`).
- **Categories**: ASSET PCG makes assets; LEVEL GEN makes chapters; AUDIO makes sound; see `skills-map.md`.
- **Terminal Lab**: the dev page `/terminal-lab`, a test bench for the terminal. Not a content category; it writes no chapter and no comix.
- **Item**: something the developer carries in his **inventory** (`src/game/inventory.ts`): the tube transistor (`tube_transistor`), the terminal, the laptop, the manual, the map. One model per item (`item.<name>`, category `item`) and one hero model per held item (`vibecoder.dev` holds the tube transistor, `vibecoder.dev_<item>` the rest). `inventory` / `inv` list them; `hold <item>` takes one in hand. Spec: `.kiro/specs/inventory/` and its child specs.
- **Chapter Motherboard Map**: PCB-styled interactive chapter popup dialog (`#chapter-map-dialog` on `/play`, `src/ui/chapter-map.ts`, `src/ui/chapter-map-model.ts`) opened via `#hud-map`, `.item-slot.item-map`, `F3`, or `map [level]`; keeps battle turn timer running. Spec: `.kiro/specs/inventory/items/map/`.
- **Laptop Lab**: the dev page `/laptop-lab`, the emulator of the developer's laptop and its coding **tasks** (`src/laptop/domain/tasks.ts`). Not a content category; it writes no chapter and no comix.
- **Lab script**: one `scripts/harness/terminal-lab/<id>.lab.json`: a `setup` list (the scene: `file`, `dir`, `socket`, `enemy`, `pickup`, `patch`, `prop`, `npc`, `taunt`, `dialogue`, `riddle`, `task`, `check`) and a `steps` list (`run`, `tick`, `emit`, `inject`, `say`, `taunt`, `dialogue`, `check`, `wait`, `expect`). It compiles to a throwaway one-level pack plus a `LabConfig`, never to `src/chapters/generated/`.
- **Riddle**: a lab socket that speaks a prompt on `cat` and checks the answer written to it.
- **Goal** (lab): a thing to do in a lab level, shown with a done mark: a **task** (a game win rule placed in a lab), a **check** (a lab-only condition: `ran`, `output`, `code`, `event`, `file`, `riddle`), or a riddle.
- **Pattern** (lab): plain text matches as a substring (a riddle answer: the exact text); `re:<regex>` or `re:/<regex>/<flags>` is a regular expression. The prefix keeps a path such as `/dev/null` plain text.
- **Absorbed damage**: damage a lab session counts per source and never applies.
- **Kiro spec**: one folder `.kiro/specs/<name>/` (`requirements.md` or `bugfix.md`, `design.md`, `tasks.md`) for a feature or a big refactor. Not a chapter spec. Its `Status:` is `draft`, `requirements-approved`, `design-approved`, `approved` or `done`; code is written only from `approved` on (`spec-first.md`).
- **Agent** (team): one Kiro custom agent in `.kiro/agents/<name>.json`: `lead-dev`, `terminal-designer`, `laptop-designer`, `comix-designer`, `chapters-designer`, `artist`, `sound-designer`, `qa`. Its **owned paths** are the only files it writes; every source file has exactly one owner. Not an AI-agent character of the story (Clod, Gork, Codec, Anti-Gravy); `kiro disclaimer` (`kiro legal` / `kiro.d disclaimer`) prints the in-game parody, AWS trademark & post-Kiroween rework notice and `npm run quality:brands` (`scripts/quality/check-brands.mjs`) enforces that no real AI agent brand names appear in the repo.
- **QA report**: one `docs/qa/<YYYY-MM-DD>-<scope>.md` written by `qa`: the checks run with exit codes, the findings with owners, a `PASS` / `FAIL` verdict.
- **Property** (test): an invariant checked on many generated inputs by `scripts/harness/property-tests.mjs` (fast-check). A failure gives a shrunk **counterexample** and a seed.
- **Grill**: the rounds of questions the agent asks before a Kiro spec leaves `draft`. Answers are recorded under `## Decisions`; unanswered ones stay under `## Open questions`.
- **Achievement**: one of the 15 declarative local trophies in `src/chapters/achievements.ts` (`out-of-credits:achievements:v1`), paired 1:1 with a Steamworks `ACH_*` API key, surfaced via `achievements` (`ach`, `trophies`), the HUD toast, `/` and `/chapters.html`, and never recorded in `preview` or `lab` sessions.
